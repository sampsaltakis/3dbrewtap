# 3DBrewTap

Website for custom 3D printed tap handles.

Live domain: 3dbrewtap.com

## Local
Open `index.html` or run `python3 -m http.server 8080`

## Deploy on Vercel
1. Import this repo in Vercel
2. Framework: Other
3. Deploy
4. Add domain 3dbrewtap.com

## Note
Upload the `images/` folder in GitHub if photos are missing (Add file → Upload files).
